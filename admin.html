আপনার Firebase Console-এ Realtime Database-এর Rules লক করা রয়েছে (Permission Denied)। সবার মোবাইলে ভিডিও দেখতে ও ডাটা লোড হতে নিচের রুলসটি Firebase Console → Realtime Database → Rules-এ গিয়ে Publish করে দিন:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
(রুলস পাবলিশ করার পর পেজটি একবার রিফ্রেশ করুন)

নতুন ক্যাটাগরি তৈরি করুন। আপনি যে ক্যাটাগরিগুলো তৈরি করবেন শুধুমাত্র সেগুলোই হোমপেজের ফিল্টারে এবং ভিডিও আপলোডের সময় প্রদর্শিত হবে।

অ্যাডস্টেরা বিজ্ঞাপন কনফিগারেশন (Adsterra Integration)

বিজ্ঞাপন চালু রাখুন:

আপনার Adsterra পাবলিশার অ্যাকাউন্ট থেকে প্রাপ্ত ব্যানার, নেটিভ, বা পপআন্ডার স্ক্রিপ্ট কোডগুলো নিচে পেস্ট করুন। কোড খালি রাখলে হোমপেজে কোনো বিজ্ঞাপন দেখানো হবে না।

এই বিজ্ঞাপনটি ভিডিও গ্রিডের উপরে প্রদর্শিত হবে।
🔥 হাই সিপিসি 🔞 Adult Ready

💡 নিচে বড় বিজ্ঞাপন বসানোর নিয়ম: Adsterra ড্যাশবোর্ডে গিয়ে আপনার সাইটে 300x250 (Medium Rectangle) অথবা Native Banners (4x1 / 4x2) অথবা 728x90 অ্যাড ইউনিট যুক্ত করুন। এরপর প্রাপ্ত স্ক্রিপ্ট কোডটি হুবহু নিচের বক্সে পেস্ট করুন। এটি ওয়েবসাইটের ভিডিও গ্রিডের নিচে বড় সাইজে স্বয়ংক্রিয়ভাবে ফিট হয়ে প্রদর্শিত হবে।

এই বিজ্ঞাপনটি ওয়েবসাইটের নিচে ভিডিও তালিকার ঠিক পরে বড় পরিসরে প্রদর্শিত হবে। অ্যান্টি-অ্যাডব্লকার শিল্ড দ্বারা এটি সব ব্রাউজারে সুরক্ষিত থাকবে।
হাই ইনকাম
Adsterra পাবলিশার ড্যাশবোর্ড থেকে Direct Link / Smartlink তৈরি করে সেই লিংকটি এখানে পেস্ট করুন। এটি ব্যবহারকারীদের ভিডিও প্লেয়ারে ডাউনলোড/ওয়াচ বাটনে ক্লিকে রিডাইরেক্ট করবে।

এটি ওয়েবসাইটের একদম উপরে মেসেজ বা চ্যাট নোটিফিকেশনের মতো ভেসে ওঠে। ব্যবহারকারী এতে ক্লিক করলে সরাসরি আপনার অ্যাডস্টেরা স্মার্টলিংক বা অ্যাডের লিংকে চলে যাবে।

সাইট ব্র্যান্ডিং ও কনফিগারেশন

এই নামটি পরিবর্তন করে সেভ করলেই হোমপেজের লোগো, টাইটেল ও ফুটারে সাথে সাথে আপডেট হয়ে যাবে।

নিরাপদ Firebase Realtime Database Security Rules

নিচের রুলস কোডটি কপি করে Firebase Console -> Realtime Database -> Rules ট্যাবে পেস্ট করে Publish করুন:

{ "rules": { "videos": { ".read": true, ".write": true, "$videoId": { ".read": true, ".write": true, "views": { ".validate": "!newData.exists() || newData.isNumber()" }, "likes": { ".validate": "!newData.exists() || newData.isNumber()" } } }, "categories": { ".read": true, ".write": true }, "settings": { ".read": true, ".write": true } } }

☁️ Firebase Cloud Storage Security Rules

যদি আপনি Firebase Cloud Storage ব্যবহার করে সরাসরি গুগল ক্লাউডে ভিডিও ফাইল হোস্ট করতে চান, তবে Firebase Console -> Storage -> Rules ট্যাবে নিচের কোডটি পেস্ট করে Publish করুন:

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /{allPaths=**} { allow read, write: if true; } } }
